## Overview
These beginner projects focus on **mastering fundamentals from scratch** using pure Python, NumPy, and local open-source tools without cloud bills or complex infrastructure.

---

### Project 1: Autograd Engine & Mini-Transformer from Scratch
- **Stack:** Pure Python, NumPy
- **Key Concepts:** Reverse-mode automatic differentiation, computational graph topological sorting, backpropagation through tensor operations, multi-head causal self-attention, and layer normalization.
- **Companion Lab:** [`notebooks/deep-learning/03_mini_transformer_attention.ipynb`](../../notebooks/deep-learning/03_mini_transformer_attention.ipynb)
- **Companion Module:** [`curriculum/06-production-ai/13_algorithms_from_scratch.md`](../../curriculum/06-production-ai/13_algorithms_from_scratch.md)

---

### Project 2: Real-Time Edge Computer Vision & Multi-Object Tracker
- **Stack:** OpenCV, ONNX Runtime, ByteTrack, YOLOv10 / YOLO11
- **Key Concepts:** NMS-free object detection on edge hardware, Kalman filter-based multi-object tracking, polygon zone occupancy detection, and real-time HUD rendering at 45+ FPS.
- **Hardware:** Consumer laptop webcam or video file.
- **Companion Module:** [`curriculum/04-generative-ai/05_nlp_cv_and_multimodal.md`](../../curriculum/04-generative-ai/05_nlp_cv_and_multimodal.md)
