## Overview

Phase 2 transitions from foundations to machine learning and deep representation learning. The focus is strictly on production rigor:
- **Leak-free preprocessing pipelines** and cost-sensitive evaluation (PR-AUC, cost matrices under extreme churn/fraud imbalance).
- **Core Deep Learning (04A):** Computational graphs, autograd backprop, custom PyTorch training loops, and LayerNorm/RMSNorm implementations.
- **Advanced Deep Learning & RL (04B):** Distributed Data Parallel (DDP), Fully Sharded Data Parallel (FSDP), memory optimization, Policy Gradients (REINFORCE), PPO, and alignment fundamentals (RLHF, DPO, GRPO).

## Prerequisite Guidance
- Complete [Phase 1: Foundations](../01-foundations/README.md) or pass the Linear Algebra & Calculus diagnostic sections.
- **Module 04A** is mandatory for all ML, GenAI, and Agentic AI engineering tracks.
- **Module 04B** is an optional advanced specialization for systems engineers and distributed training practitioners.
