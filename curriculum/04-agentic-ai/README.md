## Overview

Phase 4 represents the signature curriculum track of this repository. It progresses from basic tool calling and bounded reasoning loops to distributed multi-agent systems and enterprise governance:
- **Module 07 (Agent Fundamentals):** Workflows vs. Agents decision framework, ReAct loops, AST sandboxing, and working memory.
- **Module 08 (Agent Orchestration):** Strict JSON Schema tool contracts, LangGraph cyclical state machines, Google ADK, and Human-in-the-Loop (HITL) interrupts.
- **Module 09 (Multi-Agent Systems & MCP):** Supervisor-worker topologies, context isolation, FastMCP JSON-RPC 2.0 servers, and Agent-to-Agent (A2A) protocol.
- **Module 10 (Agent Evals, Safety & FinOps):** Golden evaluation datasets, trajectory benchmarking, indirect prompt injection guardrails, and token budget FinOps.
