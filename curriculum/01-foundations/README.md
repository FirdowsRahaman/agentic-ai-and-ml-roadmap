## Overview

Phase 1 provides the mathematical, statistical, and software engineering bedrock required to build production AI systems. Rather than treating math as academic theory or Python as simple scripting, this phase teaches:
- **Vectorized computing** with NumPy memory layouts and broadcasting.
- **Data engineering** with SQLite CTEs, window functions, and DuckDB.
- **Matrix calculus & linear algebra** (SVD, Eigenvalues, multivariate chain rule).
- **Probability & hypothesis testing** (Bayes' Theorem under extreme class imbalance, Central Limit Theorem, A/B conversion Z-tests).
